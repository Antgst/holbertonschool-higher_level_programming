# Python Import Modules

## Description
This project focuses on importing functions/variables, command-line arguments, and module execution flow.

## Learning Objectives
- Import functions and variables from other files.
- Use `if __name__ == "__main__":` correctly.
- Handle command-line arguments with `sys.argv`.
- Discover names from compiled/hidden modules.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.

## Project Files
- `0-add.py`
- `1-calculation.py`
- `2-args.py`
- `3-infinite_add.py`
- `4-hidden_discovery.py`
- `5-variable_load.py`

## Usage
```bash
python3 2-args.py hello world
```
