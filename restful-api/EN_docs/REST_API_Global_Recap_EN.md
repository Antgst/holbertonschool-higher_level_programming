# 🌍 REST API Module — Global Recap (T0 → T5)

## 📌 Overall Objective

This module progressively builds a complete understanding of:
- HTTP fundamentals
- API consumption
- Backend development
- API security and authentication

Each task adds one architectural layer.

---

# 🧱 Learning Progression

## T0 — HTTP / HTTPS Foundations
Focus:
- HTTP request / response structure
- Methods and status codes
- Difference between HTTP and HTTPS
- Security basics (TLS)

Core skills:
- Read and interpret HTTP traffic
- Understand client → server communication
- Identify common status codes

---

## T1 — API Consumption with curl
Focus:
- Command-line HTTP requests
- GET / POST requests
- Headers inspection
- JSON responses

Core skills:
- Use curl as a debugging tool
- Interpret API responses
- Understand how frontend talks to backend

---

## T2 — API Consumption with Python
Focus:
- requests library
- JSON parsing
- Data transformation
- Exporting structured data (CSV)

Core skills:
- Programmatic API interaction
- Data manipulation
- Structured data export

---

## T3 — Building a Server with http.server
Focus:
- Creating a basic HTTP server
- Manual routing
- Sending headers and status codes
- Returning JSON

Core skills:
- Understand backend mechanics
- Construct raw HTTP responses
- Handle 404 errors properly

---

## T4 — Building an API with Flask
Focus:
- Routing with decorators
- JSON responses with jsonify
- Dynamic routes
- Handling POST requests
- Error handling

Core skills:
- Structured backend development
- REST endpoint design
- HTTP status management

---

## T5 — API Security & Authentication
Focus:
- Basic Authentication
- JWT Authentication
- Role-based access control
- Strict 401 handling

Core skills:
- Authentication vs Authorization
- Token-based security
- Protecting endpoints
- Implementing RBAC

---

# 🎯 What You Are Expected to Master

By the end of T5, you should:

- Understand HTTP deeply
- Consume APIs via curl and Python
- Build APIs manually and with Flask
- Return structured JSON responses
- Handle errors properly
- Secure endpoints using authentication
- Implement role-based permissions

This module forms the foundation of backend engineering.
