
# 🌍 Module API REST — Récapitulatif Global (T0 → T5)

## 📌 Objectif Global

Ce module construit progressivement une compréhension complète de :

- Les fondamentaux HTTP
- La consommation d’API
- Le développement backend
- La sécurité et l’authentification des APIs

Chaque tâche ajoute une couche architecturale.

---

# 🧱 Progression pédagogique

## T0 — Fondamentaux HTTP / HTTPS
Focus :
- Structure requête / réponse HTTP
- Méthodes et codes de statut
- Différence HTTP vs HTTPS
- Bases de la sécurité (TLS)

Compétences clés :
- Lire et interpréter du trafic HTTP
- Comprendre le modèle client → serveur
- Identifier les codes de statut courants

---

## T1 — Consommation d’API avec curl
Focus :
- Requêtes HTTP en ligne de commande
- Requêtes GET / POST
- Inspection des headers
- Lecture de JSON

Compétences clés :
- Utiliser curl comme outil de debug
- Interpréter une réponse API
- Comprendre comment un frontend appelle un backend

---

## T2 — Consommation d’API avec Python
Focus :
- Bibliothèque requests
- Parsing JSON
- Transformation de données
- Export CSV

Compétences clés :
- Interaction programmatique avec une API
- Manipulation de données structurées
- Export vers format standard

---

## T3 — Création d’un serveur avec http.server
Focus :
- Création d’un serveur HTTP simple
- Routing manuel
- Envoi de headers et status codes
- Retour JSON

Compétences clés :
- Comprendre les mécanismes internes d’un backend
- Construire une réponse HTTP manuellement
- Gérer proprement les erreurs 404

---

## T4 — Création d’une API avec Flask
Focus :
- Routing via décorateurs
- JSON avec jsonify
- Routes dynamiques
- Gestion des requêtes POST
- Gestion des erreurs

Compétences clés :
- Développement backend structuré
- Conception d’endpoints REST
- Gestion correcte des status codes

---

## T5 — Sécurité & Authentification API
Focus :
- Basic Authentication
- JWT Authentication
- Contrôle d’accès basé sur les rôles (RBAC)
- Gestion stricte des erreurs 401

Compétences clés :
- Authentification vs Autorisation
- Sécurité par token
- Protection d’endpoints
- Implémentation de rôles admin/user

---

# 🎯 Ce que tu dois maîtriser

À la fin de la T5, tu dois :

- Comprendre HTTP en profondeur
- Consommer des APIs via curl et Python
- Construire une API manuellement et avec Flask
- Retourner des réponses JSON structurées
- Gérer correctement les erreurs HTTP
- Sécuriser des endpoints
- Implémenter un contrôle d’accès par rôles

Ce module constitue la base du développement backend.
