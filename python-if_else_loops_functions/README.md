# Python If Else Loops Functions

## Description
This project practices control flow, loops, and simple function definitions in Python.

## Learning Objectives
- Use `if`, `elif`, and `else` correctly.
- Iterate with `for` and `while`.
- Work with ASCII values and character operations.
- Create and call Python functions with parameters and return values.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and PEP8-compliant.
