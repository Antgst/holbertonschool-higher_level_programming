# Python More Data Structures

## Description
This project extends data structure practice with sets, dictionaries, lambda, and functional helpers like `map`.

## Learning Objectives
- Use dictionaries for key/value data modeling.
- Work with set operations and uniqueness.
- Apply lambda and higher-order tools (`map`).
- Solve transformations with clean, readable code.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.
