# Python ABC

## Description
This project introduces abstract base classes, duck typing, inheritance composition, and iterator customization.

## Learning Objectives
- Create abstract base classes with enforced methods.
- Apply duck typing principles in Python.
- Extend built-in types with custom behavior.
- Build custom iterators that preserve state.
- Combine inheritance to model richer objects.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.

## Project Files
- `task_00_abc.py`
- `task_01_duck_typing.py`
- `task_02_verboselist.py`
- `task_03_countediterator.py`
- `task_04_flyingfish.py`
- `task_05_dragon.py`

## Usage
```bash
python3 main_00_abc.py
```
