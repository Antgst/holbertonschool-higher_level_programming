# Python Test Driven Development

## Description
This project practices TDD by implementing functions with strict specifications and validating behavior through doctests and unit tests.

## Learning Objectives
- Write functions from clear specifications.
- Validate edge cases and input types.
- Use doctests and Python unit tests.
- Build reliable, maintainable utility functions.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Style: PEP8 / pycodestyle
- Tests should pass with `python3 -m unittest` and doctest tooling.

## Project Files
- `0-add_integer.py`
- `2-matrix_divided.py`
- `3-say_my_name.py`
- `4-print_square.py`
- `5-text_indentation.py`
- `tests/0-add_integer.txt`
- `tests/2-matrix_divided.txt`
- `tests/3-say_my_name.txt`
- `tests/4-print_square.txt`
- `tests/5-text_indentation.txt`
- `tests/6-max_integer_test.py`

## Usage
```bash
python3 -m doctest -v 0-add_integer.py
python3 -m unittest discover tests
```
