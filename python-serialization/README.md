# Python Serialization

## Description
This project covers serializing and deserializing data in multiple formats: JSON-style objects, pickle, CSV, and XML.

## Learning Objectives
- Convert Python objects into storable/transmittable formats.
- Restore serialized data back into Python objects.
- Compare serialization formats and their tradeoffs.
- Implement simple persistence workflows.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.

## Project Files
- `task_00_basic_serialization.py`
- `task_01_pickle.py`
- `task_02_csv.py`
- `task_03_xml.py`

## Usage
```bash
python3 main_00_basic_serialization.py
```
