# SQL Introduction

## Description
This project covers the SQL basics used to manipulate relational databases with MySQL: creating databases/tables, inserting data, selecting rows, filtering, ordering, and aggregating.

## Learning Objectives
- Understand what a database is and how relational tables are organized.
- Use SQL statements to create and manage databases and tables.
- Insert, update, and query data with `SELECT`, `WHERE`, `ORDER BY`, and `LIMIT`.
- Use aggregate functions like `COUNT()` and `AVG()`.
- Apply constraints and basic data integrity rules.

## Requirements
- OS: Ubuntu 20.04 LTS
- SQL engine: MySQL 8.0 (or compatible)
- SQL files should be executable by MySQL CLI.
- Every SQL file starts with a comment describing the task.
