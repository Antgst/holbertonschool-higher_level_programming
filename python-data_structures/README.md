# Python Data Structures

## Description
This project practices lists, tuples, indexing, slicing, and common operations on Python data structures.

## Learning Objectives
- Access and modify elements in lists and tuples.
- Use list methods and sequence operations.
- Build and transform lists safely.
- Handle matrices and tuple-based returns.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.
