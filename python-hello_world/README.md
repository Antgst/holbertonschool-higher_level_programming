# Python Hello World

## Description
First Python project: interpreter basics, output, strings, formatting, and small scripts.

## Learning Objectives
- Run Python scripts from the command line.
- Print text, numbers, and formatted values.
- Manipulate strings with slicing and concatenation.
- Follow basic Python style conventions.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- First line of scripts: `#!/usr/bin/python3`
- Files should end with a newline and be executable.

## Project Files
- `2-print.py`
- `3-print_number.py`
- `4-print_float.py`
- `5-print_string.py`
- `6-concat.py`
- `7-edges.py`
- `8-concat_edges.py`
- `9-easter_egg.py`

## Usage
```bash
python3 2-print.py
```
