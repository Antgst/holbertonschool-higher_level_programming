# Python Classes

## Description
This project introduces object-oriented programming with a `Square` class across multiple iterations.

## Learning Objectives
- Define classes and instances in Python.
- Encapsulate attributes with validation.
- Use methods to expose object behavior.
- Implement `__str__` and utility methods.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.

## Project Files

- `1-square.py`

- `6-square.py`
