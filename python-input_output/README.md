# Python Input Output

## Description
This project focuses on file handling and serialization in Python (text files, JSON conversion, and object dictionaries).

## Learning Objectives
- Read and write text files safely.
- Append data without overwriting existing content.
- Convert Python objects to/from JSON strings.
- Save/load JSON data from files.
- Represent class instances as dictionaries for serialization.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.
