# Python Exceptions

## Description
This project introduces error handling in Python using `try`, `except`, `finally`, and custom exception raising.

## Learning Objectives
- Catch and handle runtime errors safely.
- Separate normal flow from error flow.
- Raise built-in exceptions intentionally.
- Build robust functions that keep running on partial failures.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.

## Project Files
- `0-safe_print_list.py`
- `1-safe_print_integer.py`
- `2-safe_print_list_integers.py`
- `3-safe_print_division.py`
- `4-list_division.py`
- `5-raise_exception.py`
- `6-raise_exception_msg.py`

## Usage
```bash
python3 0-main.py
```
