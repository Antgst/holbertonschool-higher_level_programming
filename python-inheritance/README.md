# Python Inheritance

## Description
This project covers inheritance, type checking, subclassing, and abstract geometry classes in Python.

## Learning Objectives
- Understand inheritance and polymorphism fundamentals.
- Check object types with `isinstance` and subclass relationships.
- Create child classes extending parent behavior.
- Build reusable class hierarchies.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python: 3.8+
- Scripts should be executable and style-compliant.
